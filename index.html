Patterns

1-Way Horizontal/VerticalCircles grow from small to large in one direction from centre.
2-Way Horizontal/VerticalRecursive circles branching symmetrically in one axis.
2-Way Inv H/VLike 2-Way but circles grow larger toward the edges.
4-Way + / CrossBoth axes simultaneously.
3D 2-Way HorizontalTrue 3D perspective 2-Way horizontal branching rotating in space.
3D 4-Way +True 3D perspective recursive circles rotating in space.
Kaleidoscope ×8/×12Mirrored wedge radial symmetry.
SpiralCircles along a rotating expanding spiral arm.
Fractal TreeBranching organic tree that sways and breathes.
LissajousStacked harmonic orbit rings per depth level.

Colour

StaticSingle theme colour, no cycling.
CycleAuto-advances through all themes in order.
RandomPicks a random theme each interval.
Multi-strobeEach depth ring gets a different colour offset.

Animation

Global speedScales all animation speeds in unison.
Frequency checkboxEnables pulse animation. The slider sets oscillation speed.
Sync breathSyncs the pulse timing to the rotation timeline instead of the pulse timeline, aligning breathing swells with rotation.
Pulse DistanceHow far circles breathe in and out.
Pulse shiftPhase offset per depth level, creating a ripple wave effect.
ConvergeCollapses all circles toward a single concentric point. 0=normal, 1=fully collapsed.
Orbiting depth rotationtwist/rotate nested depths independently.
Wobble AmplitudeSecondary radius modulation layered on top of pulse.
Wobble FrequencySpeed of the wobble oscillation.
Trail lengthLower value = longer trails (less bg clear per frame).
↔ Ping-pongSlider oscillates between its min and max automatically.
🎚️ Limits buttonSet custom min/max extents for ping-pong animation.
↺ Reset buttonResets a single slider to its default value.
Pattern Cycle/RandomAuto-cycles through render patterns (similar to colour cycling).

FX

BlendCanvas composite operation. Lighter=additive glow; Difference=inversion.
RippleDisplaces each circle centre by an animated sine-wave offset.
Chroma SplitRGB lens aberration via screen-blend offset copies.
ScanlinesCRT-style horizontal lines overlay.
VignetteRadial edge darkening.
Feedback EchoPrevious frame blended back in — high values create tunnel feedback.
